# 「债券基金」功能生成规范（提示词）

> 理财工作台功能之一，与「行业板块」「指数跟踪」共用同一套手机卡片界面范式。
> 面向**普通家庭**：平常买宽基指数基金与债券基金、未来准备买房、不做短线、看重本金波动与流动性。
> 所有结论用大白话、短句、给得出做法，不堆术语、不荐个股、不预测点位。

## 1. 功能定位

- 名称：**债券基金**，与「指数跟踪」同样的界面（橙色顶栏 + 债券市场横卡 + 颜色图例 + 今日一句话 + 卡片流 + 页尾灰字依据）。
- 更新：**每天 14:00（Asia/Shanghai）更新**，周末与法定节假日顺延至下一交易日；**不设底部导航条 / 标签栏**，页尾以数据来源、更新规则、灰字技术依据与免责声明收口。
- 三大板块：① 基金排名 TOP5　② 基金自选　③ 债券市场晴雨表；另在自选详情内嵌「买入记录 · 相对上次买入」与顶部「买入跌幅提醒 + 手机弹窗消息」。

## 2. 数据源规则（唯一，禁止编造）

| 用途 | 真实来源 |
|---|---|
| 全市场场外债券型基金近三年收益 | 天天基金 `rankhandler.aspx?op=ph&dt=kf&ft=zq`（`dt=kf` 即开放式场外可申购） |
| 基金累计/单位净值全序列、名称 | 天天基金 `pingzhongdata/<code>.js`（`Data_ACWorthTrend` / `Data_netWorthTrend`） |
| 基金类型 / 可申购校验 | 天天基金 `FundSearchAPI.ashx`（`FTYPE` / `ISBUY`） |
| 债券指数实时行情 / 日 K | 东方财富 `push2 stock/get`、`push2his kline/get`（国债指数 1.000012、企债指数 0.399481、中证转债 1.000832） |
| 债券政策快讯 | 东方财富 7×24 快讯 `getFastNewsList?biz=web_724&fastColumn=102`（全天翻页） |
| 官方新闻 | 中国人民银行、财政部官网新闻栏目 |
| 买入流水 / 弹窗提醒配置 | 本机 `data/buy-records.json`、`data/popup-config.json`（页面录入或设置后导出） |

- **禁止** Yahoo Finance / Tushare / Bloomberg / 非 neodata 或上述以外的行情源；禁止占位数据、禁止虚构数值与新闻。
- 任一接口失败如实降级并标注 `partial` / `degraded`，不编造、不用估算顶替真实值。
- 每条数据都要能追溯：渠道状态 + trace（provider / endpoint / note）。

## 3. ① 基金排名

- 样本：全市场**场外可购买**债券型基金全量（本期约 5070 只），要求成立满三年且近三年收益有效。
- **异常剔除**：近三年收益 > 50% 的样本通常为巨额赎回导致净值异动，非可持续收益，剔除并在依据中写明数量与阈值（本期剔除 9 只）。
- 回撤：按近三年收益降序取头部 120 只候选，逐只用**累计净值**（含分红再投资）计算近三年最大回撤 `max[(峰值−谷值)/峰值]`；不混用单位净值口径。
- 综合分 = `0.6 × 收益排名分位 + 0.4 × 回撤排名分位`（候选池内按名次线性映射 0~100，回撤越小分越高）。
- 展示**前 5 名并附基金代码**：名次、名称、代码、近三年收益、近三年最大回撤、综合分、收益分/回撤分进度条、净值日期与回撤峰谷区间。
- 同一基金的 A/C/E 份额按名称归一后**去重**，保证 5 只不同基金。
- 最大回撤 / 近一月回撤**仅作行情展示**，不再作为提醒触发条件（提醒已改为「买入跌幅」，见第 4 节）。

## 4. ② 基金自选 + 买入记录 + 手机弹窗提醒（本次改版核心）

> 由「近一月回撤 > 0.5% 发浏览器通知」改为「记录最新买入时间，次日更新和上次买入时间点相比的涨跌幅，跌幅超过 0.7% 时微信通知」；
> **本次再改为**：「跌幅超过 0.7% 时**手机页面自动弹出消息卡片提醒**」，不再使用任何微信推送网关、无需密钥。

- 初始自选：**005909**（华泰保兴尊利债券C，债券型-混合二级）。
- 交互：输入 6 位基金代码添加；**上移 / 下移**自由调整前后顺序；自由删除；顺序即推送顺序；清单存 `localStorage`。
- 编辑结果标注**次日 14:00 更新生效**；新增代码在采集前显示「待更新」，不得用假数据填充。
- 列表三列（实时指数 / 涨幅估值 / 涨跌）右对齐、`tabular-nums`，**红涨绿跌**。
- 每只基金展开后展示 5 个主项：**当天实时指数、涨幅估值、成交量、估值高低、未来走势预估**，技术面三段（趋势 / 区域 / **相对买入**）与近 60 日累计净值 + BOLL 三轨 SVG。
- 口径必须写清（场外债基无盘中盘口）：实时指数 / 成交量 → 对标债券指数实时行情；涨幅估值 → 对标指数盘中涨幅估算（非官方）；估值高低 → 非 PE、累计净值近 250 交易日分位；未来走势 → BOLL+MACD+均线五因子，注明仅技术倾向。

### 4.1 买入记录（记录最新买入时间）

- 每只基金详情内嵌「买入记录 · 相对上次买入」卡：录入**买入日期 / 金额 / 成交净值**（净值留空则按买入日或之前最近交易日从天天基金**真实单位净值序列**带出，绝不编造）。
- 支持多笔买入、逐笔删除；「最近一次买入时间点」即日期最大的一笔，作为涨跌幅基准。
- 买入记录存 `localStorage`；「导出买入记录」生成 `data/buy-records.json` 文本，替换后供次日 14:00 定时任务读取。
- 页面即时用注入的真实 `navSeries` 试算「相对上次买入涨跌幅」，四宫格展示最近买入时间 / 买入净值 / 最新净值 / 涨跌幅（红涨绿跌），并标注触发状态徽章。

### 4.2 相对上次买入涨跌幅（次日更新口径）

- `涨跌幅 =（最新单位净值 ÷ 最近一次买入净值 − 1）× 100%`，单位净值口径、逐条可回验。
- **次日 14:00 更新**：定时任务重新采集净值 → `sources/fetch_bonds.py` 用 `compute_since_buy()` 重算每只基金的 `sinceBuy` → 顶部提醒条与详情即时刷新。
- `sources/notify_popup.py` 独立复算同一口径并负责组装弹窗消息；两处口径一致，避免漂移。
- 债券基金波动极小，本期真实数据（005909 从 2026-09-10 买入 1.3172 → 2026-11-10 最新 1.3155 = **-0.13%**）**未触发**，页面如实显示「买入跌幅监控中 · 暂无提醒」，**禁止编造触发值**。

### 4.3 买入跌幅手机弹窗提醒（跌幅 > 0.7%）

- 触发条件：相对上次买入**跌幅 > 0.7%**（即 `涨跌幅 ≤ -0.7%`）。
- **提醒方式（本次改版）**：手机页面在**打开时自动弹出居中消息卡片**（纯前端、无外部推送网关、无密钥、开箱即用）。卡片列出触发基金、买入日/净值、最新净值、涨跌幅与阈值，配「知道了」「查看自选」按钮；点「知道了」后按日期写入 `localStorage`，**同一天只弹一次**。
- 可选补充：手机状态栏系统通知走浏览器 `Notification API`，需在页面「提醒设置」里开启并授权，且要求 HTTPS / localhost；未授权或不支持时**如实降级为仅页内弹窗，不谎报已送达**。
- **后端职责**：`sources/notify_popup.py`（次日定时任务的一环）复算触发态、组装消息（title / content / items）、写 `data/popup-notify-log.json`（`popupStatus`：`popup_ready` / `skipped_no_trigger` / `disabled` / `test_ready` + `popupDetail`）；脚本**不调用任何外部网关、不发送微信/短信**，真正弹出由页面完成，绝不谎报已弹出。
- 支持 `python3 sources/notify_popup.py --test`（生成测试弹窗消息）与 `--dry-run`（只算不写日志，校验用）。
- **诚实原则**：未触发 → `skipped_no_trigger` 不弹窗；触发但用户在设置里关闭 → `disabled` 不弹窗；页面文案与日志状态一致。
- 顶部提醒条：触发时橙红（列出基金、买入日、买入/最新净值、涨跌幅、阈值），未触发时绿色「监控中」；含「提醒设置」「测试弹窗」按钮与弹窗开关状态、上次提醒日志。
- 「提醒设置」弹层：手机弹窗开关、状态栏系统通知开关（含浏览器权限提示）、阈值展示、测试弹窗、上次提醒记录、复制配置到 `data/popup-config.json`。

## 5. ③ 晴雨表

- 依据：**最新债券政策 + 官方新闻**（东财 7×24 快讯全天翻页 → 国内债市主体白名单；央行 / 财政部官网 → 债券政策强相关标题）。
  - 必须排除海外利率、股票回购增持、黄金、公司票据、会见/人事等误命中；标题、时间、来源逐条可回验，取不到日期如实标「日期未取到」。
- 技术面：国债指数近 250 日日 K → BOLL(20,2)、%B、带宽、MACD(12,26,9)、MA5/20/60、20 日斜率、近 250 日分位；给出趋势 / 区域 / 走势三段。
- 晴雨判定：技术分 0~10 + 政策分 −2~2，合计封顶 0~10 → **晴 ≥7.5 / 多云转晴 ≥6 / 多云 ≥4.5 / 阴 ≥3 / 雨**。
- 必须输出：晴雨标识 + 综合分、今日债券市场行情分析（含位置风险提示）、给普通家庭的做法、政策与官方新闻列表、国债指数近 60 日走势 SVG。
- 政策新闻仅作定性参考，不用于预测；结论标注"技术倾向，不预示未来"。

## 6. 界面规范

- `viewport` 移动端优先，容器上限 480px，单列卡片流；**不设底部导航条**。
- 方框格子大小合适：主展示 2 列小方格（末项占整行）、技术面 3 列小格、买入四宫格 2×2、晴雨技术 3 列、排名评分条。
- **禁止一长条横向排版文字**：窄栏短句、`word-break`，`nowrap` 只用于短数字/标签。
- 顶部固定**颜色图例**：红＝上涨/偏强、绿＝下跌/偏弱/偏低、橙＝偏高/顶部/风险，蓝灰＝中性/合理/震荡；涨跌遵循 A 股惯例**红涨绿跌**。
- 图标一律**纯 CSS**（不依赖 emoji 字体）；页面**完全自包含**，除数据来源标注外无外部 CDN。
- 页尾固定：**分析依据（灰字备注）**——排名口径、异常剔除、回撤公式、综合分公式、**相对买入涨跌幅口径 / 买入跌幅弹窗提醒规则 / 手机弹窗与系统通知说明**、实时指数/涨幅/成交量/估值口径、BOLL/MACD/趋势/区域/走势公式、晴雨评分、新闻来源、时间基准，以及**逐只基金原始数值**（含相对买入涨跌幅）；再列渠道状态、trace、免责声明。

## 7. 页脚固定内容

- 顶部「14:00 更新」语义与下次更新倒计时、净值截至日期。
- 免责：AI 基于公开行情整理，仅供参考，**不构成投资建议**；场外债基最终收益以基金公司公布净值为准；相对买入涨跌幅基于历史单位净值，不代表未来表现；买入跌幅提醒为手机页面弹窗消息，需在页面打开时才会弹出，系统通知需另行授权浏览器通知权限；历史收益与最大回撤不代表未来表现，技术分析不预示未来。
- 明确说明：跌幅超阈值时本页面在手机屏幕中央弹出消息卡片（纯前端、无需微信、无需密钥）；打开页面才会弹出、同一天只弹一次；状态栏系统通知需浏览器授权且要求 HTTPS / localhost，未授权时仅页内弹窗，页面如实标注、不谎报已送达。

## 8. 运行链路（命令）

```bash
cd bond-funds
python3 sources/fetch_bonds.py          # 全量排名/回撤/行情/净值/新闻 + 相对买入涨跌幅 → bond-feed.json + bond-snapshot.json
python3 sources/notify_popup.py         # 买入跌幅判定 + 组装手机弹窗消息 → popup-notify-log.json（--test 测试 / --dry-run 只算不写）
python3 scripts/generate_briefing.py    # 组装 + 注入 index.html + 写 push-<date>.md
```

- 定时：`0 0 14 * * *`（Asia/Shanghai）。沿用前序模块做法：**平台定时任务未创建**，仅保留命令链路。
- 清单/记录/配置文件：`data/watchlist.json`（自选 codes）、`data/buy-records.json`（买入流水）、`data/popup-config.json`（弹窗提醒开关 / 系统通知意向 / 阈值），编辑后由界面「复制清单 / 导出买入记录 / 复制配置」导出替换，次日采集生效。
- `notify_popup.py` 必须在 `generate_briefing.py` **之前**运行，页面才能展示最新的「上次提醒」状态。
- 页面真正弹出弹窗的判定在前端 `currentDrops()` + `maybeAutoPopup()`（按日期去重），与后端日志口径一致但独立可验。
