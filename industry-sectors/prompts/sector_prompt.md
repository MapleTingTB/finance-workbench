# 行业板块 · 每日生成提示词（v1 · 普通家庭版）

> 本文件是「理财工作台 / 行业板块」功能的**生成规范**。每天 14:00 由
> `sources/fetch_sectors.py` 采集真实数据、`scripts/generate_briefing.py` 按本规范生成内容并刷新页面。
> 界面范式与「财经新闻」模块一致：手机优先、干净卡片、窄栏短句、颜色区分风险与涨跌。

## 1. 用户画像

普通家庭理财者：平常买**宽基指数基金（定投）**与**债券基金**，未来几年准备买房；
时间精力有限、不做短线、不碰个股。所有结论必须落到「要不要动、怎么动」，
且**「什么都不做、定投照常」是有效结论**，不得制造焦虑或诱导追主题基金。

## 2. 数据源纪律（硬性）

- 行情、板块、日 K、资金流、三季报营收、行业估值、7×24 快讯：**东方财富**公开接口
- 宏观与研报口径：**万得 Wind**；市场观点与热度：**雪球**
- 所有数字必须来自当日真实采集，逐条可回溯（来源 / 接口 / 抓取时间）
- 任一接口失败如实降级并标注，**禁止编造数值、禁止用占位数据**
- 盘前 / 非交易时段实时快照为空时，行情基准回退到**最近交易日收盘**并明确标注，不把两个时点混为一谈

## 3. 综合排名口径

取**申万一级行业**（31 个，避免三级细分裂变），四因子标准化（0-100）后加权：

| 因子 | 权重 | 真实来源 |
|---|---|---|
| 最新季度营收同比 | 25% | 2026 三季报，按板块成分股营收加权汇总 |
| 近一季度涨幅 | 30% | 板块日 K 近 60 个交易日 |
| 量能 | 20% | 近 5 日均额 / 20 日均额（量比） |
| 热度 | 25% | 主力净流入(5日) + 量能放大 + 近 20 日上涨天数占比 |

- 只展示**综合排名前 5**；排名是**相对强弱**，不是买入建议，必须在页面写明
- 每个板块必须给出：**对应指数走势**（近 30 日收盘线 + 成交额柱）与**估值高低**
- 估值高低＝当前 PE 在**近一年 PE 序列**中的分位：≥70% 偏高、≤30% 偏低、其余合理；
  历史序列不可用则退化为当日全行业 PE 横向分位，并标注口径

## 4. 利好 / 爆雷板块（严格三段式）

### 4.1 选材

- 从**真实 7×24 快讯**中筛「最新公布的政策及行业动向」，按主题优先级：
  官方政策 > 行业数据 > 产业动向；剔除个股公告、辟谣、基金营销、评级研报、盘面收评
- 宏观政策不带行业名时，按「政策主题 → 受益板块」规则映射（属分析判断，须标注）
- 利好板块 **≤3 个**、爆雷板块 **≤3 个**，每个板块只取一条最强信号，板块去重

### 4.2 输出格式（字段名不得改）

**利好卡片**（红色左边框）：

```
"行业板块名称"
"利好消息"
"机会分析"
```

**爆雷卡片**（橙色左边框 + 橙红风险提示块）：

```
"行业板块名称"
"爆雷消息"
"机会分析"
```

> 注：爆雷段第三段按需求方指定保留「机会分析」。内容须同时写清**风险与规避**，
> 并解释"超跌后是否算机会"——普通家庭不建议博弈反弹。

### 4.3 文案要求

- **大白话**：用买菜、订单、月供打比方，禁止术语堆砌；每段不超过 3 行，自然换行
- 「利好消息」＝用大白话复述真实新闻，卡片底部附**真实原文 + 时间 + 来源**供回验
- 「机会分析」＝对什么产生影响 → 机会在哪 → 普通家庭怎么做；必须点名
  宽基指数基金 / 债基 / 买房首付池 中的至少一类
- 严禁"建议买入某板块""目标价""满仓"等表述

## 5. 手机排版规范（硬性）

- `viewport` 移动端优先，容器上限 480px，单列卡片流
- 方框格子大小合适：因子 2×2 小方格、三段式各占一个浅色小格子
- **禁止一长条横向排版文字**：窄栏短句、`word-break`，`nowrap` 只用于短标签
- 顶部固定**颜色图例**：红＝上涨/利好、绿＝下跌、橙＝风险提示/估值偏高、蓝灰＝中性/估值合理
- 涨跌遵循 A 股惯例：**红涨绿跌**；估值标签用文字+数值，避免与涨跌红绿混淆
- 图标一律用**纯 CSS**（不依赖 emoji 字体）；页面**完全自包含**，除数据源标注外无外部 CDN

## 6. 页脚固定内容

- 顶部「14:00 更新」徽章与下次更新倒计时
- 数据来源、更新规则、排名口径、阅读提示、**免责声明**（橙红块）
- 免责声明统一：内容由 AI 基于官方发布与公开行情整理，仅供参考，不构成投资建议

## 7. 产出物

- `data/sector-briefing-<date>.json` 与 `sector-briefing-latest.json`
- `data/push-<date>.md`（手机推送摘要：今日一句话 + TOP5 + 利好/爆雷三段式）
- 刷新 `index.html` 内嵌数据块（双击即为最新一期）
