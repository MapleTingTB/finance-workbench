# 指数跟踪 · 每日生成提示词（v1 · 普通家庭版）

> 本文件是「理财工作台 / 指数跟踪」功能的**生成规范**。每天 14:00 由
> `sources/fetch_funds.py` 采集真实数据、`scripts/generate_briefing.py` 按本规范生成内容并刷新页面。
> 界面范式与「行业板块 / 财经新闻」一致：手机优先、干净卡片、窄栏短句、颜色区分风险与涨跌；
> 列表区参考**东方财富自选股**：橙色顶栏 + 大盘横卡 + 「名称/代码 · 最新 · 涨幅 · 涨跌」紧凑三列。

## 1. 用户画像

普通家庭理财者：平常买**宽基指数基金（定投）**与**债券基金**，未来几年准备买房；
时间精力有限、不做短线、不碰个股。结论必须落到「要不要动、怎么动」，
**「什么都不做、定投照常」是有效结论**，不得制造焦虑或诱导追单日大涨的主题基金。

## 2. 数据源纪律（硬性）

- 基金名称/类型：**天天基金 FundSearchAPI**；历史单位净值（260 条）：**pingzhongdata + f10/lsjz**
- 跟踪标的指数的实时点位/涨跌幅/成交量/成交额：**东方财富 push2**；250 日日 K：**push2his**
- 顶部大盘横卡（上证/深证/创业板）：**东方财富 push2**
- 所有数字来自当日真实采集，逐条可回溯（接口 / 抓取时间 / 口径）
- 任一接口失败如实降级并标注，**禁止编造数值、禁止用占位数据**
- 场外指数基金**无盘中盘口**：「实时指数」＝其跟踪标的指数行情；「涨幅估值」＝按指数涨幅推算的估算值，
  与基金公司次日公布的净值可能有偏差，页面必须写明这一点

## 4. 每只基金主展示（5 项，硬性）

```
当天实时指数 / 涨幅估值 / 成交量 / 估值高低 / 未来走势预估
```

| 项目 | 真实来源 | 口径说明 |
|---|---|---|
| 当天实时指数 | 标的指数 push2 最新点位 | 非基金净值，是跟踪指数 |
| 涨幅估值 | 标的指数实时涨跌幅 | 盘中估算，另列「已确认净值日涨幅」 |
| 成交量 | 标的指数成交额（亿元）+ 成交量（手） | 场外基金自身无成交量 |
| 估值高低 | 近 250 日收盘点位分位 | ≥70% 偏高 / ≤30% 偏低 / 其余合理；**相对位置，非 PE** |
| 未来走势预估 | BOLL + MACD + 均线 + 带宽综合打分 | 偏强震荡 / 区间震荡 / 偏弱调整 |

## 5. 技术面分析（必须有依据，灰字备注在页面最后）

| 指标 | 参数与公式 | 判定 |
|---|---|---|
| 布林线 BOLL | (20, 2)：中轨 MA20，上下轨 ±2σ，%B、带宽 | %B 与 250 日分位各半 → 顶部/中部/底部 |
| MACD | (12, 26, 9)：DIF/DEA/柱，金叉死叉 | DIF>DEA、柱走强 → 动能转强 |
| 均线 | MA5 / MA20 / MA60 + MA20 近 5 日斜率 | 五因子打分 → 上涨/下跌趋势/震荡整理 |

- 趋势与区域必须同时给用户明确结论：**上涨趋势还是下跌趋势**、**顶部/中部/底部区域**
- 每只基金的 BOLL 中上轨下轨、%B、带宽、DIF/DEA/柱、均线、斜率、分位——**原始数值逐条列出**
- 页尾灰字区块统一列公式、参数、判定规则、局限；并逐只列出该基金原始指标数值
- **严禁**"目标价""建议满仓""一定上涨"等表述

## 6. 辅助买基金（交易明细 → 次日更新）

- 每只自选基金可录入**当天交易明细**：交易日期 / 买或卖 / 金额 / 成交净值（留空自动取该日净值）
- 明细保存在**本机浏览器 localStorage**，不上传
- 次日 14:00 采集到新净值后，前端自动重算并展示：
  - **持有收益**（市值 − 成本）、**收益率**、**从第一次买入到现在的涨跌幅**（净值口径）
  - 持有份额、最新净值、当前趋势与区域（来自技术面）
- 计算口径写进页尾依据：`份额＝金额÷净值`、`市值＝份额×最新净值`、
  `收益率＝收益÷成本`、`首次至今涨跌幅＝最新净值÷首次买入净值−1`
- 未录入明细时不显示 0 收益，而是提示「录入后次日更新展示」，避免误导

## 7. 自选清单编辑（可自由增删 / 排序）

- 初始清单：`012769 / 004343 / 007029 / 012734 / 003359 / 011036 / 020900`
- 界面通过**输入 6 位基金代码**添加；编辑态可**上移 / 下移 / 删除**；支持按涨幅临时排序
- 顺序即推送顺序，保存在 localStorage；顶部「复制清单」导出 `watchlist.json` 供工作台同步
- 新增代码若不在当期采集数据中，显示「待次日 14:00 采集后补全」，**不编造数值**
- 编辑后于**次日 14:00（Asia/Shanghai）**随定时任务重新采集更新；周末节假日顺延

## 8. 手机排版规范（硬性）

- `viewport` 移动端优先，容器上限 480px，单列卡片流
- 方框格子大小合适：主展示 2 列小方格、技术面 3 列小格、收益 2×2 小格
- **禁止一长条横向排版文字**：窄栏短句、`word-break`，`nowrap` 只用于短数字/标签
- 顶部固定**颜色图例**：红＝上涨/偏强、绿＝下跌/偏弱/偏低、橙＝偏高/顶部/风险、蓝灰＝中性/合理/震荡
- 涨跌遵循 A 股惯例**红涨绿跌**；列表三列（最新/涨幅/涨跌）右对齐、`tabular-nums`
- 图标一律**纯 CSS**（不依赖 emoji 字体）；页面**完全自包含**，除数据源标注外无外部 CDN
- 不设底部导航条 / 标签栏；页尾以数据来源、更新规则、灰字技术依据与免责声明收口，页面底部不留固定栏占位

## 9. 页脚固定内容

- 顶部「14:00 更新」语义与下次更新倒计时
- **分析依据（灰字）**：公式 + 参数 + 判定规则 + 逐只基金原始数值
- 数据来源、追溯、更新规则、阅读提示、**免责声明**（橙红块）
- 免责声明统一：内容由 AI 基于公开行情整理，仅供参考，不构成投资建议；
  场外基金以公布净值为准，技术分析不预示未来

## 10. 产出物

- `data/fund-feed.json`（原始采集 + trace）、`data/fund-snapshot.json`（标准化）
- `data/fund-briefing-<date>.json` 与 `fund-briefing-latest.json`
- `data/push-<date>.md`（手机推送摘要：大盘 + 今日一句话 + 自选表格）
- 刷新 `index.html` 内嵌数据块（双击即为最新一期）

## 11. 定时链路（命令）

```
cd index-tracking
python3 sources/fetch_funds.py && python3 scripts/generate_briefing.py
```
Cron：`0 0 14 * * *`（Asia/Shanghai），次日按 `data/watchlist.json` 清单重新采集。
